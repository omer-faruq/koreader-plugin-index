Install on your device

  1. In KOReader, open Tools → App Store and tap the gear icon.
  2. Choose Install plugin from URL.
  3. Type these two values:
Repository owner
Repository name

The copy buttons help if you are reading this on the device itself; otherwise just type them in.

Search tuning

Defaults come from testing against this catalogue. Two of them are floors and only go up — spending more can buy better answers, but searching less than what was tested only buys worse ones.

Raising it finds answers that rank poorly on keywords, at more tokens a question. 40 is the floor — below it the tested answers start dropping off the end of the list.
A ceiling, not a target — the model returns only what genuinely fits, which is often one or two.
Characters of description and feature list per candidate. 1080 is the floor: under it the model starts judging plugins on their opening slogan rather than what they do.
